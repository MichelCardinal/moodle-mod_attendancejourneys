# Security policy

The current release is 1.1.0-rc12, a release candidate. It is not a promise of production support or Marketplace approval. Test it in staging before production use.

Do not disclose vulnerabilities, credentials, student records or exploit details in public issues. When private vulnerability reporting is enabled for this repository, use its Security tab. Before publication, the maintainer must enable that channel or publish an appropriate private contact. No response-time service commitment is made.

Report the exact plugin/Moodle/PHP/database versions, affected capability and context, reproduction steps using fictional data, and impact. A maintainer should acknowledge the report, reproduce it in an isolated environment, preserve relevant evidence, prepare a fix and coordinate disclosure after testing.

Older candidates are retained as development history; use the current candidate for evaluation. The first stable release and its support policy will be announced separately.
