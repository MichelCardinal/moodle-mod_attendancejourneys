# Security policy

The current release is Attendance Journeys 1.1.0. Test installations and upgrades in staging before production use. Marketplace review and approval are independent of source publication.

Do not disclose vulnerabilities, credentials, student records or exploit details in public issues. Private vulnerability reporting is enabled: use [Report a vulnerability](https://github.com/MichelCardinal/moodle-mod_attendancejourneys/security/advisories/new). No response-time service commitment is made.

Report the exact plugin/Moodle/PHP/database versions, affected capability and context, reproduction steps with fictional data, and impact. The maintainer should reproduce the issue in isolation, preserve evidence, prepare a tested correction and coordinate disclosure.

Pre-publication candidates are historical development archives. Future maintained releases use the same mod_attendancejourneys component; test upgrades and consult the changelog. Do not use predecessor-component ZIP replacement as a data migration.
