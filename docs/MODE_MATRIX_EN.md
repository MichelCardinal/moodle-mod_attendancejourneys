# Light and Professional mode matrix

| Feature | Light | Professional |
|---|:---:|:---:|
| Individual sessions | Yes | Yes |
| Calculated duration, delivery modes and optional calendar | Yes | Yes |
| Present, absent, partial, excused and unrecorded | Yes | Yes |
| Self-recording and approval | Yes | Yes |
| Essential collective and individual reports | Yes | Yes |
| Percentage, threshold, grades and completion | Yes | Yes |
| Advanced series and bulk operations | No | Yes |
| Main journey and individual final closure in new activities | Yes | Yes |
| Additional simultaneous journeys and advanced journey management | No | Yes |
| Capacity and waitlist | No | Yes |
| Cross-journey equivalences | No | Yes |
| Reusable rooms and Moodle group management | No | Yes |
| Exceptional administration and institutional audit | No | Yes |

“No” means the feature is removed from navigation and protected server-side; existing Professional data is not deleted if an activity is temporarily switched to Light mode.
