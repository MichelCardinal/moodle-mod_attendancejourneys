# Matriz de modo ligero y profesional

| Característica | Light | Profesional |
|---|:---:|:---:|
| Sesiones individuales | Sí | Sí |
| Duración calculada, modos de entrega y calendario opcional | Sí | Sí |
| Presente, ausente, parcial, justificado y no registrado | Sí | Sí |
| autorregistro y aprobación | Sí | Sí |
| Informes colectivos e individuales imprescindibles | Sí | Sí |
| Porcentaje, umbral, calificaciones y finalización | Sí | Sí |
| Operaciones avanzadas en serie y a granel | No | Sí |
| Itinerario principal y cierre final individual en actividades nuevas | Sí | Sí |
| Itinerarios simultáneos adicionales y gestión avanzada de itinerarios | No | Sí |
| Capacidad y lista de espera | No | Sí |
| Equivalencias entre itinerarios | No | Sí |
| aulas reutilizables y gestión de grupos Moodle | No | Sí |
| Excepcional administración y auditoría institucional | No | Sí |

“No” significa que la función se elimina de la navegación y se protege en el lado del servidor; Los datos profesionales existentes no se eliminan si una actividad se cambia temporalmente al modo Light.
