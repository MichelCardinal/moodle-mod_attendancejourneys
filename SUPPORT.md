# Support and maintenance

Use the Issues tab for bugs and feature requests, and Discussions if the maintainer enables it. Documentation is included in docs and in the activity Help centre. Site administrators can access the administrator guide without a course activity.

This is an independent community activity module licensed under GPL v3 or later. No subscription, external API key or paid service is required. It is not an official Moodle product and is not yet approved by Moodle Marketplace. No commercial support or response-time guarantee is included.

A journey means sessions grouped within this activity, not a multi-course programme. Attendance Journeys focuses on attendance minutes and final results after explicit closure. Planning, capacity and waiting-list features must be explained in the Marketplace product-scope review; acceptance is decided by Moodle.

Validated locally on Moodle 4.5 through 5.3 with MySQL, and Moodle 5.3 with PostgreSQL 17. PHP and database minimum versions are determined by the Moodle release. No Moodle App or Iomad certification is claimed. VoiceOver testing is deferred; keyboard, labels and responsive checks are documented separately.

Before upgrades, back up the database and moodledata, then test the same package in staging. Preserve closed results and protected grades. Document any correction, increment the technical version, retain prior distributions and publish clear release notes. New language strings must be kept synchronized with AMOS after approval.
